## 1. 这份稿子是什么

一次完整的界面重构，不是给现有页面换皮：

- **重排信息架构**：设备选择、会话浏览、目标选择、传输状态各自归位，一屏只有一个主按钮。
- **重画全部界面**：主面板、多选、校验、推送、确认、队列、整包迁移预检、分片传输详情、空态、异常、拖拽、设置、窄窗、诊断。
- **给出可落地的规范**：语义 token、组件状态、键盘与读屏、断点、组件拆分与验收清单。
- **本轮界面重构不改宿主半边**：发现（UDP）、HTTP 传输、SHA-256 校验、`state.json`、槽位注册保持原样。
- **整包文件迁移是 v2 的独立传输层**：新增迁移预检/传输详情（06a/06b）与宿主传输引擎，设计见 [`docs/architecture/session-bundle-transfer.md`](../architecture/session-bundle-transfer.md)。

打开方式：

```sh

open "dsh-session-sync/docs/redesign/index.html?focus=s-main"
# 指定主题与语言
```

## 2. 目标与非目标

### 目标

1. 打开面板 3 秒内能回答：**谁在线、我选中了谁、这台设备有什么、我现在能做什么**。
2. 「把某个会话弄到某处」这条主路径不超过 **3 次点击**：选设备 → 选会话 → 选目标并开始。
3. 传输过程**不遮住**会话列表；失败能就地看到原因并重试。
4. 与 DSH 设置页同一套语言：同样的行高、控件高度、分隔线、深浅主题；不引入外部字体/图标库。
5. 键盘可完成完整流程；状态不只靠颜色。

### 非目标

- 本轮界面重构不新增网络能力（发现、端口、会话 JSON 传输、校验算法不变）；整包文件迁移是 v2 的独立传输层，单独排期。
- 不做会话内容预览、编辑、合并；插件仍然只负责搬运。
- 不引入虚拟滚动、动画库、图表库或任何运行时依赖。
- 不重写宿主侧栏 DOM；拖拽仍走现有的 `data-row-key` 探测。

## 3. 设计假设（如不成立请指出）

1. **主面板是主战场**，设置页是低频入口；设置可以退化成单栏，但功能不能少。
2. 典型设备数 2–5 台，会话数几十到几百；列表不需要虚拟化。
3. 使用环境以 macOS/Windows 桌面为主，触屏是少数；但 `hover` 不能是完成任务的唯一方式。
4. 深浅主题跟随宿主；插件不提供独立配色。
5. 面板宽度 ≥ 720px 时可用双栏；更窄时设备栏变成设备条。

## 4. 现状诊断（为什么重画）

| # | 现状 | 后果 |
|---|---|---|
| 1 | 一个页面从上到下堆了头、本机名、设备+会话、本机工作区、队列、设置、页脚 | 面板里要滚很久；设置和操作混在一起 |
| 2 | 设备行有 `⋯` 菜单 + 「一键同步」，右栏头部又有「拉取全部」，行内还有「拉取」 | 同一个动作三个入口，用户不知道主操作是哪个 |
| 3 | 方向写成「对端会话 / 本机会话」 | 需要先反推“这是拉还是推” |
| 4 | 「已选 0 个」工具条常驻 | 空选择态占掉列表第一行，看起来像坏了 |
| 5 | 选择条里的「拉取到」和页面底部「本机工作区」都在表达落点 | 两个“目标”入口，规则不一致 |
| 6 | 传输抽屉从右侧盖住列表 | 想再挑几个会话必须先关抽屉 |
| 7 | 校验结果、复制摘要、拉取、清除全挤在行内 | 失败时行高变化，列表跳动 |
| 8 | 空态/错误只有一段说明文字 | 用户不知道下一步该点哪 |

## 5. 新信息架构

```
会话同步（sidebar.panellist → main）
├─ 顶栏：标题 · 在线/已发现 · 刷新 · 设置
├─ 设备栏（只负责“选谁”）
│  ├─ 本机卡：名称（就地改名）· 地址（复制）
│  ├─ 在线 / 离线 分组：设备行（状态点 · 名称 · 地址 · 会话数）
│  └─ 底部：添加地址 · 跨网段扫描
└─ 会话台（针对选中设备）
   ├─ 头部：设备 · 地址 · 会话数 · 平台/版本 · 拉取全部 · ⋯
   ├─ 方向：拉取 N / 推送 N + 一行流向说明
   ├─ 工具：搜索（/）· 全部/未同步/已同步 · 排序
   ├─ 列表：会话行（勾选 · 标题 · #id/时间/路径/事件数 · 状态 · 拉取/校验）
   │  └─ 校验摘要（就地展开：通过一行，失败两段）
   ├─ 选择条（仅选中时）：已选 N · 目标目录 ▾ · 开始 · 清除
   └─ 传输坞：总进度 → 向上展开队列（逐条状态/耗时/重试）

设置视图（同一组件）：身份 / 传输 / 高级 / 关于
宿主设置页（settings.section）：同一组行，单栏容器
```

### 关键决策

1. **设备栏去动作化。** 重命名、复制地址、刷新、移除收进会话台头部的 `⋯`。设备行只剩“点它”。
2. **方向就是标签。** `⇣ 拉取 42` / `⇡ 推送 80`，并在下方用一句话写清流向；不再出现“对端会话/本机会话”。
3. **目标目录只有一个入口。** 选择条的 `目标目录 ▾` 同时列出未分组、工作区、自定义路径；页面底部「本机工作区」整段删除。拖到宿主工作区仍然有效，是同一概念的快捷方式。
4. **选择条按需出现。** 没有选择时不存在；有选择时贴列表底边浮出，Esc 或「清除」收起。
5. **状态常显，动作按需。** 行末状态徽章永远在；拉取/校验在 hover、聚焦、触屏时出现。状态和动作在视觉上分开。
6. **校验就地展开，不跳页。** 成功只占一行；失败展开两段摘要 + 409 原因，主操作是「重新校验」，不提供“忽略继续”。
7. **队列是坞，不是抽屉。** 底部一条总进度；展开后从下往上长，列表仍可滚动、仍可继续勾选。
8. **设置是面板内视图。** 顶栏「设置」进入、返回按钮回会话台；宿主设置页复用同一组行，只换容器。
9. **确认标题带目标。** 「拉取 4 个会话到『未分组』」；重复项逐个三选一（保留本机/覆盖本机/跳过）。
10. **空态给出下一步。** 本机地址可复制、手动地址可添加、跨网段扫描可进入；不用先去设置里找。
11. **所有颜色来自宿主。** 本稿的 hex 只是 DSH token 的深/浅两套回退值，落地时换成 `--dsw-alias-*`。
12. **键盘与读屏是一等公民。** 见 §9。

### 6.2 字体与阶梯

系统字体栈，机器数据（地址、id、路径、摘要、耗时）用等宽；不引入 webfont。

| 角色 | 字号/行高/字重 |
|---|---|
| 页面标题 | 20 / 28 / 600 |
| 区块标题、设备名 | 15 / 22 / 600 |
| 行标题 | 14 / 22 / 550（列表内 13.5 / 19 / 400） |
| 正文、按钮 | 13 / 20 / 400–550 |
| 说明、辅助 | 11.5–12.5 / 16–20 |
| 机器数据 | 10.5–11.5 mono |

### 6.3 尺寸

- 间距：4 / 8 / 12 / 16 / 20 / 24 / 32（4 的倍数，禁止奇数值）。
- 圆角：6 徽章 → 8 输入/小按钮 → 10 按钮 → 12 浮层/内卡 → 16 面板卡 → 999 开关/toast。
- 控件高：24 xs / 28 sm / 30 输入 / 32 默认 / 36 顶栏；会话行 47；设备行 ~50。
- 描边：统一 `.5px`；浮层用阴影，不用粗边框。
- 图标：16/14/12px 线性图标，`stroke-width 1.5`，`currentColor`；方向图标（拉取/推送）是整套界面的签名。

### 6.4 动效

| 场景 | 动作 | 时长 |
|---|---|---|
| 行 hover | 底色 0 → 4.5% | 120ms |
| 选择条 | 上移 4px + 淡入 | 160ms |
| 目标浮层 | 上移 3px + scale .99 | 140ms |
| 确认弹窗 | 上移 6px + scale .99 | 180ms |
| 传输坞展开 | 高度增长（不遮罩） | 220ms |
| 进度条 | 宽度过渡 | 320ms |
| 旋转 | 仅 running 状态 | 750ms linear |

`prefers-reduced-motion: reduce` 下所有过渡降到 0.01ms，进度直接跳变；spinner 不做装饰性循环。

## 8. 页面状态矩阵

| 页面状态 | 触发 | 表现 |
|---|---|---|
| 首屏 | 有在线设备 | 自动选中第一台在线设备并加载会话 |
| 无设备 | 0 台发现 | 设备栏显示空；会话台给地址、手动地址、三步说明 |
| 设备离线 | 心跳超时 | 头部点变空心 + 「离线」；列表标注“上次读取”；主按钮禁用 |
| 加载中 | 会话未返回 | 3 行骨架，保持 47px 行高 |
| 无结果 | 搜索/筛选后 0 条 | 保留查询词 + 「清除筛选」 |
| 读取失败 | API 报错 | 行内错误块（原因 + 重试），不清空已有列表 |
| 空列表 | 设备确实 0 个会话 | 一行说明，不画骨架 |
| 传输中 | 队列有 running | 底部坞 + 行内「拉取中」；进度 49% 为整批，43% 为当前条目 |
| 完成 | 全部结束 | 坞变「完成 N 项」；3 秒后自动收起（可手动展开） |
| 校验失败 | 409 checksum-mismatch | 行内红条：两段摘要 + 重新校验；不写入 |
| 渲染异常 | 错误边界 | 诊断页：错误、栈摘要、平台/Node/宿主/端口、重新加载、复制 |

## 9. 交互、键盘与无障碍

### 指针

**命中区是整行**：标题、元信息、状态徽章、行内空白都能切换选择。勾选框只是把状态显性化，不是唯一的入口。点击行内「拉取/校验」、菜单、下拉或链接不触发选择；拖选文字后松手也不误触。`Shift` + 点击连选，`⌘/Ctrl` + 点击追加。

### 键盘

| 键 | 行为 |
|---|---|
| `/` | 聚焦搜索 |
| `↑` `↓` | 移动焦点行（不改选择） |
| `Space` | 选中/取消焦点行 |
| `Enter` | 拉取（或推送）焦点行 |
| `⌘A` | 全选当前方向 |
| `Shift` + 点击 | 从锚点连选 |
| `Esc` | 清空选择 / 关浮层 / 关弹窗 |
| `Tab` | 只在可交互元素间移动；弹窗内循环 |

### 无障碍

- 焦点环：`2px` 品牌色 + `1px` offset，任何主题下可见；不删除 outline。
- 设备行 `role="option" aria-selected`；勾选框 `role="checkbox" aria-checked`；方向 `role="tablist"`。
- 弹窗 `aria-modal="true"`；打开时焦点进入，关闭后回到触发按钮。
- 传输进度放入 `aria-live="polite"`，只在阶段变化时播报（开始/完成/失败），不逐字节播报。
- 状态不只靠颜色：徽章同时有图标和文字。
- 触控：`@media (hover:none)` 下动作常显，图标按钮命中区 44px。
- 目标菜单、确认弹窗、诊断页均在 200% 缩放下不横向滚动（文本可换行，路径可截断）。

## 11. 文案与 i18n

- 所有产品文案继续走插件自己的字典；场景里用 `data-en` 演示英文长度，英文预览只覆盖产品文案。
- 新增：`target.*`（目标目录、当前、添加路径、拖到工作区）、`state.*`（离线、上次读取、无结果、读取失败）、`queue.*` 补充（清除已完成、等待 worker）。
- 删除：`devices.tabPeer` / `devices.tabLocal`（被方向标签替代）；`settings.ports` 的重复展示收敛到高级区。
- 文案原则：动作即标签；不写“点击这里”；失败写原因和下一步；数量带单位（个会话 / 条事件）。
