一个人的局域网，两个屏幕之间的对话

这是「会话同步」插件的完整界面重构稿：从主面板、会话选择、传输确认、队列、整包迁移预检、分片传输详情，到设置、空态、拖拽、异常和窄窗口，全部重画。设计目标是让整套操作像一台安静的仪器——一屏一个主按钮，状态永远可见，动作永远在它发生的地方。

所有界面沿用 DSH 自己的设计变量、控件高度与深浅主题，不引入外部字体、图标库或品牌色。稿子里的每个状态都可以单独打开、截图、对照验收。

焦点与读屏

  • 焦点环 2px 品牌色 + 1px offset，任何主题下都可见。
  • 设备行 role="option" aria-selected；勾选框 role="checkbox" aria-checked。
  • 方向切换 role="tablist" + aria-selected。
  • 弹窗 aria-modal="true"，打开后焦点进入，关闭后回到触发按钮。
  • 传输进度放在 aria-live="polite" 区域，只在阶段变化时播报，不逐字节播报。
  • 颜色不是唯一信息：状态徽章同时带图标与文字。

触控与响应

  • 桌面图标按钮视觉 30px，命中区 32px；触屏通过 @media (hover:none) 提到 44px。
  • 行高 47px，整行可点；勾选框本身 16px，但点击热区覆盖整行，不要求对准框。
  • 断点：≥980 双栏 / 720–980 收窄设备栏 / <720 设备条。
  • 不依赖 hover 完成任何任务：拉取全部、选择条、行内动作都可用键盘到达。
  • prefers-reduced-motion 下取消所有非必要动画，进度改为瞬时更新。
取舍：不做“整页虚拟滚动”。会话数量在几十到几百，47px 行 + 浏览器滚动足够；虚拟化会把焦点管理与读屏复杂度提高一个量级，换不来可感知的收益。
  • 动效只回答“从哪来”。选择条从列表底部升起；浮层从锚点上方出现；不做无意义的位移。
  • Esc 永远能退出。浮层、弹窗、选择态都有明确的退出路径。
  • 减少动态。系统开启 reduced motion 时，所有过渡降到 0.01ms，进度直接跳变。
