设计决定与度量

项目现状建议理由
正文列64% 夹 680–920，代码同宽正文 760px，代码/表格允许 880px中文 14px 在 760px 约 54 字/行，接近 45–60 字舒适区；代码不横向滚动
用户气泡55%，圆角 1678%，圆角 16 / 右下 4短句不再被挤成 3 行，长文仍受控
行高22px（1.57）23px（1.64）中文加 1px 明显更松，不破坏密度
轮次间距12px24px（同轮内 10px）轮次边界一眼可辨
代码块无头，长行横向滚30px 头（语言 / 换行 / 复制）+ max-height 420 + 展开复制与语言识别是高频动作
工具调用逐条展开连续调用合并卡片，状态 / 耗时 / 失败可重试长会话里工具噪声占一半屏
流式底部停止按钮光标脉冲 + 磁吸 danger 停止键停止键随时可点，位置不跳
离开底部无提示>240px 出现「2 条新消息 · 回到最新」不打断阅读，又能回到流
动效较少消息进入 160ms 上移 4px；展开 180ms；hover 150ms；全部尊重 reduced-motion统一节奏，避免“突然出现”

不改什么

  • 不改 DOM 结构与既有快捷键（⌘K、↑ 编辑上一条等）
  • 不动模型选择、模式切换的位置与顺序
  • 不引入新字体；仅用现有 font stack 与 12/13/14/20 阶梯

验收口径

  • 1440 宽下正文 ≤ 760px、代码 ≤ 880px；1280 下不出现横向滚动
  • 连续 3 次工具调用在会话里只占 1 张卡
  • 流式时停止键与发送键位置完全重合
  • prefers-reduced-motion: reduce 下无位移动画
