命中规则

  • 指针落在标题行 → 该分组
  • 落在展开区的会话行 / 溢出行的任意位置（含空白）→ 向上回溯最近的标题行
  • 嵌套子分组：以最近的标题行为准
  • 「未分组」= 插件的 unsorted 目录

动效

  • 描边 / 底色：120ms cubic-bezier(.4,0,.2,1)
  • 胶囊：透明度 + scale(.98→1)，120ms
  • 离开目标：200ms 淡出，不做位移
  • 成功态停留 90ms 后进入确认弹窗

边界

  • 不改 DSH 侧栏 DOM/类名，只加临时 class
  • 胶囊 pointer-events:none，绝不挡命中
  • 目标名超长省略，最多 180px
  • 拖拽取消（Esc / 拖回原处）立即清空所有高亮
